# California House Price Prediction using XGBoost

A machine learning-based regression application that predicts California housing prices using geographical and socioeconomic features. The project implements the Extreme Gradient Boosting (XGBoost) Regressor and integrates the trained model with an interactive Streamlit web application.

## Overview

This project implements a supervised machine learning regression system designed to estimate residential property prices in California.

It uses **Extreme Gradient Boosting (XGBoost)**, an ensemble learning algorithm that builds decision trees sequentially, with each successive tree helping improve the predictive performance of the model.

The prediction considers housing-related characteristics, including:

- Number of rooms.
- Average income of the population in a location.
- Geographical latitude.
- Geographical longitude.
- Proximity to the Bay Area.

The trained XGBoost model processes the numerical input features and generates an estimated house price.

The application is deployed using Streamlit, providing an interactive interface for submitting housing configurations and obtaining price predictions.

## Key Features

- **House Price Prediction:** Estimates residential property prices in California.
- **Supervised Machine Learning:** Implements a regression-based predictive modeling approach.
- **XGBoost Regression:** Uses Extreme Gradient Boosting for numerical prediction.
- **Geographical Features:** Incorporates latitude and longitude as housing price indicators.
- **Socioeconomic Features:** Considers average population income and housing characteristics.
- **Pre-trained Model Integration:** Loads a serialized XGBoost model using Python Pickle.
- **Interactive Web Application:** Provides a Streamlit interface for generating predictions.
- **Real-Time Inference:** Produces predictions without retraining the model during application execution.

## Machine Learning Workflow

The system follows a machine learning prediction pipeline:

1. **User Input:** Collects numerical housing configuration data through the Streamlit interface.
2. **Input Processing:** Splits comma-separated values and converts them into numerical data.
3. **Feature Preparation:** Organizes the input values into a two-dimensional NumPy array.
4. **Model Loading:** Loads the pre-trained XGBoost Regressor from `Booster.pkl`.
5. **Price Prediction:** Passes the processed features to the trained model.
6. **Prediction Output:** Generates a numerical estimate of the California house price.
7. **Result Display:** Displays the predicted price through the Streamlit interface.

## Usage

The application accepts comma-separated numerical values representing the housing features used during model training.

**Input Format**

```text
feature_1, feature_2, feature_3, ..., feature_n
```

The input values must follow the exact feature order and format expected by the trained XGBoost model.

After entering the housing configuration, click the prediction button to generate the estimated house price.

*Note: The exact feature order and number of input values should be documented alongside the model's training configuration.*

## Model Implementation

The project uses the **XGBoost Regressor**, an implementation of gradient-boosted decision trees designed for efficient predictive modeling.

Unlike traditional bagging-based ensemble algorithms, XGBoost builds decision trees sequentially, with each new tree helping minimize the errors made by the existing ensemble.

The trained model is serialized and stored in:

`Booster.pkl`

During application execution, the model is loaded using Python's Pickle module and used to generate house price predictions without requiring retraining.
